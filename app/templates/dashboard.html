What's new in v0.9.0 2026-09-02
The app now tells you which build it is running
  • Settings carries a Deployment card naming the exact version and commit this app is serving. Nothing it served said so before, so “did the update actually land?” had no answer you could read off the screen.
  • The deploy checks it too, and stops if the answer is wrong. It asks the running app what it is and refuses to finish unless that matches the release just published — and it asks before any database change runs.
  • That gap was not hypothetical. This app once sat three releases out of date with every indicator green, because the only thing being checked was whether the deploy command succeeded, not what came back up afterwards.
